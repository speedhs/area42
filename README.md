# Area 42

A first-person browser prototype: a scientist trapped inside his own spatial instrument.

**Look:** cel megastructure (flat violet panels, pale sun fog, ink edges) — story and axioms unchanged.

## Run

```bash
npm install
npm run dev
```

## Controls

| Input | Action |
| --- | --- |
| ENTER HULL | Start |
| WASD / arrows | Walk |
| Mouse | Look |
| Esc | Pause / resume |
| Mute | Toggle procedural audio |

## Wings

1. **A** — Direction, attention, containment  
2. **B** — Identity (orange CRT breathes heat; green is the echo)  
3. **C** — Scale (walk into the tool drawer)

## Audio

All sound is procedural (Web Audio): wing drones, metal footsteps, CRT boots, hatch clacks, axiom stings.
